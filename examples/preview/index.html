ui-organized

four libraries, one stylesheet

One page per framework library, each rendering every component it ships in its plainest state, styled only by @ui-organized/core. Open two in adjacent tabs to compare them by eye.

These pages are for looking at. What actually proves the four libraries render the same DOM is the parity gates — an SSR gate over React, Svelte and Vue, and a browser gate over all four. A component a library does not ship yet is shown here as a gap rather than left out.
